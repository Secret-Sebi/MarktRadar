# Strategieentwicklung

Stand: 24. November 2026. TEILWEISE IMPLEMENTIERT.

Eine neue Trader-Version wird als Kandidat gespeichert und nicht eingesetzt. `pruefe()` verlangt eigene Abschlüsse, einen späteren Test, einen gemessenen Benchmark und ein besseres Ergebnis nach der gekennzeichneten Kostenannahme.

Nicht implementiert ist ein Suchlauf, der selbst Hypothesen erzeugt. Ein solcher Lauf würde denselben Test mehrfach verbrauchen. Deshalb gibt es ihn nicht.

Die festen Regeln der Trader sind keine selbst entwickelten Strategien.
