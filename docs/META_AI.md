# Meta-KI

Stand: 24. November 2026.

`ki_haendler_meta` speichert einen JSON-Text je Runde. Die Trader-Gewichte und die Krypto-Gewichte sind leer. Der Hinweis sagt, dass nicht gewichtet wird.

Die gespeicherte Marktphase kommt aus der Bewegung von DAX oder S&P 500. Ein Wechsel von seitwärts zu fallend ist eine neue Indexrechnung, keine bessere Intelligenz und keine Übernahme einer Trader-Regel.

Widersprüchliche Trader werden nicht zu einer gemeinsamen Wahrscheinlichkeit verrechnet. Solange kein Trader eine bestandene Prüfung hat, gibt es keine validierte Gewichtung. Eine Mehrheitsentscheidung wird nicht ersatzweise benutzt.
